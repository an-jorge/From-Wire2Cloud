# MCU

An **MCU** or **Microcontroller Unit** is a small computer on a single chip.

It usually includes:

* **CPU** (processor)
* **Memory** (RAM + Flash)
* **Peripherals** (GPIO, ADC, UART, I²C, SPI, etc.)

#### Key Points

* Runs simple, dedicated programs (unlike CPUs in PCs/phones that run complex OS).
* Very low power consumption.
* Cheap and widely used in IoT and embedded systems.



***

**One-sentence:**

An **MCU is a small, efficient chip that acts as the “brain” of embedded devices.**
